# Agentic Physical Reasoning

Project page for **Evaluating Physical Reasoning in LLM Agents Requires
Construction Benchmarks**, NeurIPS 2026 Position Paper Track.

- [Project page](https://ai4science-westlakeu.github.io/APR/)
- [Paper](https://openreview.net/forum?id=42PVaAYxLX)

The site uses static HTML, CSS, JavaScript, illustrations, and recorded physics
samples. The Mission Possible game loads its engine after Play. Fonts and
runtime libraries are hosted in this repository.

Library versions and licenses are listed in [game/vendor/README.md](game/vendor/README.md).
Font licenses are included with the font files. Earth imagery attribution is
shown in the game and recorded in [game/assets/earth-provenance.json](game/assets/earth-provenance.json).
